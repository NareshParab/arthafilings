# Arthafilings

Arthafilings is a document/compliance filing service platform.

## Folder layout

- `frontend/` — Next.js (App Router) frontend application. Currently the only part of the project.
- `backend/` — not yet created; planned for a future API/server layer.

## Running the frontend

```
cd frontend
npm install
npm run dev
```

Then open http://localhost:3000.
